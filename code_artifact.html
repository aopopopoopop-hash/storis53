Как устроено это приложение изнутри и как выложить его на GitHub за 2 минуты

Здесь собраны реальные куски кода из вашей настольной книги по JavaScript, которые прямо сейчас крутятся под капотом этой программы. Никакой оторванной от жизни теории — только те 7 тем, которые превращают таблицы и формулы ПЭО в работающий код.

🚀 Как закинуть на GitHub и скинуть друзьям

  1. Сохраните этот файл: на компьютере сохраните код этого приложения под именем index.html.
  2. Создайте репозиторий на GitHub: зайдите на github.com → нажмите New repository → назовите, например, finpit-app → выберите Public → нажмите Create repository.
  3. Загрузите файл: нажмите ссылку uploading an existing file → перетащите мышкой ваш файл index.html → внизу нажмите зеленую кнопку Commit changes.
  4. Включите сайт (GitHub Pages): в верхнем меню репозитория откройте Settings → слева выберите Pages → в пункте Branch выберите вместо None ветку main и нажмите Save.
  5. Готово! Через 60 секунд появится ваша прямая ссылка вида https://ваш-логин.github.io/finpit-app/. Отправьте её в Telegram Паше, Юре или друзьям!
